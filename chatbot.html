조선소 작업장 안전규정 (교육용 샘플)

이 문서는 AI 교육 실습용 샘플입니다. 공개된 산업안전보건 기준을 바탕으로 교육 목적에 맞게 요약·재구성한 것으로, 실제 사업장 규정이 아닙니다. 현장에서는 소속 사업장의 안전관리자 지침을 따르십시오.

제1조 (개인보호구)

  1. 작업장 출입 시 안전모, 안전화, 보안경을 항상 착용한다.
  2. 용접·연삭 작업 시 보안면, 방진마스크, 용접 장갑을 추가로 착용한다.
  3. 보호구가 파손되거나 없는 상태로는 어떤 작업도 시작하지 않는다. "잠깐만"도 예외가 아니다.
  4. 보호구가 없으면 작업을 중단하고 현장 안전관리자에게 지급을 요청한다.

제2조 (고소작업)

  1. 높이 2m 이상에서 작업할 때는 작업 시작 전에 안전대를 착용하고, 지정된 걸이 지점에 건다.
  2. 추락 위험이 있는 개구부와 작업 발판 가장자리에는 안전난간을 먼저 설치한다.
  3. 강풍(순간풍속 10m/s 이상), 강우, 강설 시 옥외 고소작업을 중지한다.
  4. 사다리 위에서 용접·연삭 등 양손 작업을 하지 않는다.

제3조 (밀폐공간)

  1. 탱크, 이중저, 코퍼댐 등 밀폐공간에 들어가기 전에 산소농도(18~23.5%)와 유해가스 농도를 측정하고 기록한다.
  2. 측정 결과가 기준을 벗어나면 환기 후 재측정하고, 기준에 들어올 때까지 출입하지 않는다.
  3. 출입 전 밀폐공간 작업 허가서를 발급받고, 외부에 감시인 1명 이상을 배치한다.
  4. 작업 중에도 산소농도를 계속 측정하고, 감시인은 출입구를 떠나지 않는다.

제4조 (용접·화기작업)

  1. 화기작업 전에 화기작업 허가서를 발급받고, 반경 10m 이내의 가연물을 제거하거나 불연 덮개로 덮는다.
  2. 화기작업 중에는 화재감시자를 배치하고, 소화기를 작업 위치 3m 이내에 둔다.
  3. 화재감시자는 작업 종료 후 30분간 현장을 감시한다.
  4. 가스 호스와 용접 케이블의 손상 여부를 작업 전에 점검한다.

제5조 (크레인·중량물)

  1. 크레인으로 중량물을 인양하는 동안 인양물 아래와 반경 내에 사람이 서거나 지나가지 않는다.
  2. 신호수는 1명만 지정하고, 운전자는 지정된 신호수의 신호에만 따른다.
  3. 와이어로프, 슬링, 샤클은 작업 전 점검하고 손상된 것은 즉시 폐기한다.
  4. 인양물의 무게가 정격 하중을 초과하면 인양하지 않는다.

제6조 (전기)

  1. 전기 설비 작업 전에 전원을 차단하고 잠금장치(LOTO)와 표지를 부착한다.
  2. 젖은 손이나 젖은 장소에서 전기 기기를 다루지 않는다.
  3. 피복이 벗겨진 전선과 파손된 콘센트는 사용하지 않고 즉시 신고한다.
  4. 이동식 전기 기기는 누전차단기를 거쳐 사용한다.

제7조 (화학물질)

  1. 도료, 희석제, 세척제 등 화학물질을 다루기 전에 물질안전보건자료(MSDS)를 확인한다.
  2. 화학물질을 다룰 때는 내화학 장갑과 보안경을 착용하고 환기를 유지한다.
  3. 화학물질 용기에는 반드시 내용물 표시 라벨을 부착하고, 음료 용기에 옮겨 담지 않는다.
  4. 피부에 닿거나 눈에 들어가면 즉시 흐르는 물로 15분 이상 씻고 보고한다.

제8조 (출입통제)

  1. 지정된 출입구로만 출입하고, 출입증을 항상 패용한다.
  2. 위험구역(도장 중, 방사선 검사 중, 인양 중)에는 출입 표지가 있는 동안 들어가지 않는다.
  3. 외부 방문자는 안전교육 이수 후 인솔자와 함께 이동한다.
  4. 작업장 내에서는 지정된 보행로로 이동하고 뛰지 않는다.

제9조 (비상대응)

  1. 화재, 가스 누출, 추락 등 비상 상황을 발견하면 즉시 큰 소리로 알리고 비상연락번호로 신고한다.
  2. 대피 방송이 나오면 작업을 멈추고 지정된 대피 경로로 집결지에 모인다.
  3. 엘리베이터와 크레인은 대피에 사용하지 않는다.
  4. 소화기, 비상샤워, 구급함의 위치를 작업 시작 전에 확인한다.

제10조 (사고보고)

  1. 부상, 아차사고, 설비 손상은 크기와 관계없이 당일 안전관리자에게 보고한다.
  2. 사고 현장은 조사가 끝날 때까지 보존한다.
  3. 보고 내용에는 일시, 장소, 작업 내용, 부상 부위, 목격자를 포함한다.
  4. 보고자에게 불이익을 주지 않는다.
